Once the Olympic and career progression datasets were cleaned and standardized, the next step was to generate derived analytical variables required for modeling. This section derives analysis features by enriching the tidy tables:

  • Link records to Olympic metadata.
  • Engineer age features and training age.
  • Classify event type/category.
  • Convert performances to a numeric mark (seconds for track; numeric for field).
  • Identify season-bests and distance from peak.
  • Map marks to IAAF points (rolling/closest join).
  • Convert WAC standards to points and compute the mean reference by gender.

Tidy section produced: Olympics_data_tidy, Career_progression_tidy, iaaf_table_tidy, wac_standards_tidy.

4.1 Link Career Progression to Olympics metadata

Join each performance record to athlete/event metadata, compute age at performance (age_years, age_days), and strip the “h” hand-timed suffix from performance.

Show code 
athlete_bests <-
  Career_progression %>%  inner_join(
    Olympics_data %>%  filter(!is.na(birth_date)) %>%
      distinct(birth_date, athlete_links, event, event_type, .keep_all = T) %>%
      select(name, birth_date, athlete_links, event, nationality, event_type, 
             event_category, gender, games_year),
    by = c("athlete_link" = "athlete_links", "event")
  ) %>%  
  mutate(age_years = year(date) - year(birth_date), 
         age_days = as.double(
           difftime(
             date, birth_date,units = "days"
           )
         ),
         performance = str_remove_all(performance, "h")

4.4 Map athlete performance marks to IAAF points (rolling/closest join) and join athlete_bests_clean with iaaf-table to get full dataset

For each record, find the IAAF row with the closest mark ≤ the observed mark within the same gender and event; set missing scores to 0.

Show code 
# join iaaf_table with athlete_bests_clean and get full dataset with result points
round_decimals <- function(x, digits = 2) {
  round(x * 10^digits) / 10^digits}


athlete_bests_points <- 
  athlete_bests_clean |>
    left_join(iaaf_table, join_by(gender, event, closest(mark <= mark))) |> 
  replace_na(list(points = 0))

4.5 World class standard(WAC) -> points and mean reference by gender

We harmonize WAC event labels, convert times to seconds, roll-join to IAAF points, set combined-events anchors, and compute a simple men/women mean reference useful as horizontal guide lines in plots.

Show code 
wac_points <- wac_standards_tidy %>%
  left_join(
    iaaf_table_tidy,
    dplyr::join_by(gender, Event == event, closest(mark <= mark))
  ) %>%
  tidyr::replace_na(list(points = 0)) %>%
  mutate(points = dplyr::case_when(
    Event == "Hept." & gender == "women" ~ 1174,
    Event == "Dec."  & gender == "men"   ~ 1212,
    TRUE ~ points
  ))

mean_points_by_gender <- wac_points %>%
  group_by(gender) %>%
  summarise(mean_points = mean(points, na.rm = TRUE), .groups = "drop") %>%
  tibble::deframe()
