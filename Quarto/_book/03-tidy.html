3.1 Clean Olympics_data.csv

The Olympic dataset is imported and cleaned to provide athlete-level metadata. (We standardize names, split date ranges, split gender/event, remove wheelchair entries, fix one birth date, parse dates, normalize gender, add age at Games end, create an ordered games factor, classify events, normalize an old label, add games_year, and rename nat to nationality.) Key transformations include:

-Read the CSV of Olympic track & field results. -clean_names(): lowercases and snake_cases column names. -Split the date span like “01 Aug 2012 – 12 Aug 2012” into start and end. -Split the event string’s first token into gender (“Men’s/Women’s”) and the remainder into event; too_many=“merge” keeps the rest intact. -Drop wheelchair events. -Manual data fix: overwrite a specific athlete’s birth_date. -Normalize gender to “Men/Women.” -Convert birth_date and end from “%d %b %Y” (e.g., “06 DEC 1973”) to Date. -Compute age at Games end. -Recode games to an ordered factor with readable labels. -Classify events into event_type buckets (Sprints/Middle Distance/etc.). -Classify event_category as Track vs Field. -Normalize an event label and add a games_year. -Rename nat to nationality.

parse_mark_to_seconds <- function(mark_vec) {
  sapply(mark_vec, function(mark) {
    if (is.na(mark)) return(NA_real_)
    parts <- unlist(strsplit(mark, ":"))
    parts <- as.numeric(parts)
    if (length(parts) == 3) {
      # HH:MM:SS
      return(parts[1]*3600 + parts[2]*60 + parts[3])
    } else if (length(parts) == 2) {
      # MM:SS
      return(parts[1]*60 + parts[2])
    } else {
      # Assume plain seconds
      return(as.numeric(mark))
    }
  })
}

3.5 Notes on join Behaviour

Your join uses closest on a condition with mark on both sides. That requires a recent dplyr and depends on how the IAAF reference orders marks. If you ever observe mismatched points at event boundaries, consider switching to an explicit directional rule that treats track and field differently, where track uses the largest IAAF mark that is less than or equal to the observed time and field uses the smallest IAAF mark that is greater than or equal to the observed distance or height.

The closest() join on mark requires a recent version of dplyr. If mismatches occur near event boundaries, consider refining the logic:

Track events: Use the largest IAAF mark ≤ observed time

Field events: Use the smallest IAAF mark ≥ observed distance

This directional rule ensures accurate scoring near performance thresholds.

## Notes on join Behaviour

Your join uses closest on a condition with mark on both sides. That requires a recent dplyr and depends on how the IAAF reference orders marks. If you ever observe mismatched points at event boundaries, consider switching to an explicit directional rule that treats track and field differently, where track uses the largest IAAF mark that is less than or equal to the observed time and field uses the smallest IAAF mark that is greater than or equal to the observed distance or height.

The closest() join on mark requires a recent version of dplyr. If mismatches occur near event boundaries, consider refining the logic:

Track events: Use the largest IAAF mark ≤ observed time

Field events: Use the smallest IAAF mark ≥ observed distance

This directional rule ensures accurate scoring near performance thresholds.
