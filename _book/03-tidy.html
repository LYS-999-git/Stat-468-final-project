3  Tidy

This section details the complete data cleaning and transformation process applied to the Olympic and career progression datasets. The objective is to produce a unified, well-structured dataset containing each athlete’s best annual performance, age at performance, event information, and standardized IAAF points.

The procedure involves merging competition results with athlete metadata, parsing and standardizing dates, harmonizing event names, converting performance marks to a consistent numeric scale, calculating age at performance, and integrating the IAAF 2005 points table with the cleaned and linked datasets (career progression and Olympic data).

3.1 Data Integration

This section describes the full process of integrating and tidying the datasets used in the analysis. The goal is to build a unified dataset that links athlete metadata, performance records, and standardized IAAF scoring.

3.1.1 Step 1: Clean Olympics_data.csv Data

The Olympic dataset is imported and cleaned to provide athlete-level metadata. Key transformations include:

Standardized column names using janitor::clean_names()

Parsed competition dates into start and end

Separated gender from event name

Removed wheelchair events

Manually corrected birthdate for Aminata CAMARA

Standardized gender labels (“Men’s” → “Men”, etc.)

Converted date strings to Date objects

Calculated athlete age at the time of competition

Created ordered factor for Olympic Games

Classified events into types (e.g., Sprints, Throws) and categories (Track vs. Field)

Standardized event names (e.g., merged “Javelin Throw (old)” with “Javelin Throw”)

Extracted competition year from the end date Code shows below:

Olympics_data <- read_csv("/Users/yushiliu/Stat 468 final project/data/track and field data/olympics_data.csv", show_col_types = F) %>%
  janitor::clean_names() %>% 
  separate_wider_delim(date, delim = "–", names = c("start", "end")) %>%
  separate_wider_delim(cols = event, names = c("gender", "event"), delim = " ",
                           too_many = "merge") %>%
  filter(str_detect(event, "Wheelchair", negate = T)) %>% 
  mutate(
        # Manually fixed Aminata CAMARA's age
    birth_date = if_else(name == "Aminata CAMARA", "06 DEC 1973", birth_date),
    gender = if_else(gender == "Men's", "Men", "Women"),
    across(c(birth_date, end),  ~as.Date(format(
    as.Date(., format = "%d %b %Y"), "%Y-%m-%d"))),
    age = year(end) - year(birth_date),
         games = factor(games, ordered = T,
                        levels = c("The XXXII Olympic Games",
                                   "The XXXI Olympic Games",
                                   "The XXX Olympic Games",
                                   "The XXIX Olympic Games",
                                   "The XXVIII Olympic Games",
                                   "The XXVII Olympic Games",
                                   "The XXVI Olympic Games"
                        ),
                        labels = c("Tokyo '20", "Rio '16", "London '12", 
                                   "Beijing '08", "Athens '04", "Sydney '00",
                                   "Atlanta '96")),
    event_type = case_match(
      event,
      c("100 Metres", "200 Metres", "400 Metres", "400 Metres Hurdles", "100 Metres Hurdles", "110 Metres Hurdles") ~ "Sprints",
      c("800 Metres", "1500 Metres", "3000 Metres Steeplechase") ~ "Middle Distance",
      c("5000 Metres", "10,000 Metres") ~ "Long Distance",
      c("Heptathlon", "Decathlon") ~ "Combined Events",
      c("High Jump", "Long Jump", "Triple Jump", "Pole Vault") ~ "Jumps",
      c("Shot Put", "Discus Throw", "Hammer Throw", "Javelin Throw", "Javelin Throw (old)") ~ "Throws",
      c("10 Kilometres Race Walk", "20 Kilometres Race Walk", "50 Kilometres Race Walk", "Marathon") ~ "Road Races",
      .default = "Other"
    ),
         event_category = if_else(str_detect(event, "Metres|Walk|Wheelchair") |event %in% c("Marathon"), "Track", "Field")
         ) %>% 
  mutate(event = if_else(event == "Javelin Throw (old)", "Javelin Throw", event),
         games_year = year(end)) %>% rename("nationality" = nat)

The result is a clean metadata table named Olympics_data.

3.1.2 Step 2: Clean Career Progression Data and merge with Olympic dataset

The career progression dataset is imported and cleaned to provide yearly performance records. Key steps include:

  • Removed duplicate rows

  • Parsed performance dates

  • Flagged retired athletes based on last recorded year

  • Calculated training age as years since first appearance, grouped by athlete and event

This produces a clean performance table named Career_progression. We then merge Career_progression with Olympics_data using athlete_link and event. This creates a unified dataset containing both performance records and athlete metadata. After the join, we compute:

-Age at performance:

age_years: Year of performance minus year of birth

age_days: Exact age in days using difftime(date, birth_date)

-Cleaned performance string: Removed hand-timing flags

-Numeric mark:

Track events: Time in seconds

Field events: Distance or height

-Season best indicator:

Track: Minimum time

Field: Maximum distance/height

-Percent off peak: Deviation from season best within athlete and event

-Olympic year flag: Based on season year

-Tie resolution: Within each athlete-event-year group, keep the record with the largest age in days

This final cleaned dataset is saved as athlete_bests.

# load career progression data and identify athletes who are still active
Career_progression <- read_csv("/Users/yushiliu/Stat 468 final project/data/track and field data/career_progression (2).csv", show_col_types = F) %>% 
  distinct() |> 
  mutate(date = parse_date_time(date, orders = c("%d %b %Y", "%d-%b-%y"))) %>%
  mutate(retired = if_else(max(year) <= 2022, T, F),
         training_age = year - min(year) + 1,
         .by = c("athlete_link", "event")) 

# find the seasons best performances of each athlete
athlete_bests <-
  Career_progression %>%  inner_join(
    Olympics_data %>%  filter(!is.na(birth_date)) %>%
      distinct(birth_date, athlete_links, event, event_type, .keep_all = T) %>%
      select(name, birth_date, athlete_links, event, nationality, event_type, 
             event_category, gender, games_year),
    by = c("athlete_link" = "athlete_links", "event")
  ) %>%  
  mutate(age_years = year(date) - year(birth_date), 
         age_days = as.double(
           difftime(
             date, birth_date,units = "days"
           )
         ),
         performance = str_remove_all(performance, "h") # I will count hand timed results as legitimate
         ) %>%
    mutate(mark = if_else(
      event_category == "Track",
      as.numeric(
        difftime(
          lubridate::parse_date_time2(performance, orders = c("%H:%M:%S", "%M:%S:00", "%M:%OS", "%OS"), exact = T),
          lubridate::parse_date_time2("0", orders ="S"),
          units = "secs"
        )
      ), parse_number(performance)),
      # the below accounts for edge cases that lubridate can't parse, like a 62s 400MH
      mark = if_else(is.na(mark), parse_number(performance), mark)
      ) %>%
    mutate(
      best_performance = case_when(
        event_category == "Track" & mark == min(mark, na.rm = T) ~ T, # we want the lowest time
        event_category == "Field" & mark == max(mark, na.rm = T) ~ T, # we want the furthest/highest performance
        .default = F
      ),
      percent_off_peak = if_else(event_category == "Track", abs((mark - min(mark, na.rm = T))/mark), 
                                 abs((mark - max(mark, na.rm = T))/mark)),
      olympic_year = if_else(year %in% c(seq(1980, 2016, 4), 2021), T, F),
      .by = c("athlete_link", "event")
    ) %>% 
   # remove duplicate seasons bests
  slice_max(with_ties = F, n = 1, order_by = age_days, by = c("event", "year",  "athlete_link"))

3.1.3 Step 3: Join with IAAF Points

We import the IAAF scoring table from iaaf-2025.json, flattening it into a tibble with: gender, event, mark and points.

To ensure compatibility, we create a copy of athlete_bests named athlete_bests_clean with:

-gender converted to lowercase

-event names standardized to match IAAF naming conventions (e.g., “100 Metres” → “100m”, “110 Metres Hurdles” → “110mH”)

We then join athlete_bests_clean to iaaf_table using a nearest match on mark, grouped by gender and event. This assigns an IAAF points value to each season-best record.

-The join uses closest(mark <= mark) to find the nearest valid score

-Missing points are replaced with 0 to avoid downstream errors

-The final dataset is stored as athlete_bests_points

The cleaned athlete bests dataset from the Import section was merged with the IAAF points table (iaaf-2005.json) to attach standardized scoring. Event names were harmonized between sources (e.g., "100 Metres" → "100m", "110 Metres Hurdles" → "110mH", "Marathon" → "Road Marathon").
The join was performed on gender and event using the nearest mark in the IAAF table, ensuring each record received the closest possible standardized points value. Merge to one row per athlete–event–date.

3.2 Why This Pipeline Works

-Sequential cleaning ensures each dataset is tidy before merging

-Joining Olympic and career data first preserves athlete-event-year structure

-Standardizing event names before scoring avoids mismatches

-One season-best per athlete-event-year maintains longitudinal integrity

-Numeric mark construction respects measurement scale:

Track: time in seconds

Field: distance or height

-Nearest match rule minimizes interpolation error when assigning IAAF scores

3.3 Relevant Unit Tests

  • Test 1: Check that the join produces no duplicate athlete-event-year records.
  • Test 2: Verify that every record has a valid non-missing IAAF points value after the join.
  • Test 3: Confirm that all age_years values are positive and fall within a reasonable range (e.g., 10 to 60).
  • Test 4: Check that the number of unique athlete IDs matches across the original and linked datasets. To ensure data integrity:

No duplicate athlete-event-year records after the join

All records have valid IAAF points (non-missing, non-zero)

Age values are reasonable, e.g., between 10 and 60 years

Athlete ID consistency across original and merged datasets

3.4 Notes on join Behaviour

Your join uses closest on a condition with mark on both sides. That requires a recent dplyr and depends on how the IAAF reference orders marks. If you ever observe mismatched points at event boundaries, consider switching to an explicit directional rule that treats track and field differently, where track uses the largest IAAF mark that is less than or equal to the observed time and field uses the smallest IAAF mark that is greater than or equal to the observed distance or height.

The closest() join on mark requires a recent version of dplyr. If mismatches occur near event boundaries, consider refining the logic:

Track events: Use the largest IAAF mark ≤ observed time

Field events: Use the smallest IAAF mark ≥ observed distance

This directional rule ensures accurate scoring near performance thresholds.
